## 3. Independence and sequencing

Independent G3 is a separately user-opened QA session, fresh complete clone in distinct directory, independently authored fixture/oracle/probes/mutants, direct report to work PR. Same physical Windows machine/OS/runtime profile is allowed; same-session agents, Management self-test and reused Execution results are not independent. No reuse of dirty worktree or local mutation copies; no real provider/secret data. Run each applicable workstream's unchanged full regression, mutation, egress/secret/dependency, history and exact-SHA gates. All results report environment and limitations; failures remain FAIL/PARTIAL/NOT_RUN; no certification of untested platforms. G2 and G3 are sequential separate gates: if Execution has valid environment and active authorization, missing future QA host is not by itself a technical G2 failure. Management may coordinate a pause; G3 unavailable still blocks G4, and no automatic re-dispatch after STOP.

**Dispatch safety refinement:** before editing, before local commit, immediately before push and before requesting QA, verify current active authorization/dispatch and latest STOP on the *actual work PR* (and exact expected HEAD). A known withdrawal or unverifiable bus status => STOP; no push/QA request. No timer/poll on another PR substitutes for a live check. Any later-discovered concurrent STOP or post-STOP push => disclose exact times/evidence, preserve branch as-is, halt; no automatic reset/revert/adoption. This reduces, does not eliminate, race between check and push; not an atomic remote cancellation guarantee. Applies prospectively to Management/Execution/QA; no background watcher or change to old reports.
