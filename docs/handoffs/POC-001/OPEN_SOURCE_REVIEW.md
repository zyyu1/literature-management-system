**Reuse recommendation:** start with **webdav-client** plus minimal local HTTP/WebDAV stub or optional **npm-WebDAV-Server**, each confined to `poc/001/**`. Leave **sabre/dav** as an independent fallback if local server tests need cross-stack validation. Prefer upstream npm package/integration to forking any of these projects; copying source is unnecessary without evidence. Install only the minimum approved packages, lock exact versions/lockfile and capture dependency provenance/license/security review in PR. Do not treat repository activity, Star count, or MIT/Unlicense/BSD as a safety or performance guarantee.

**Technical red lines:** for multi-device concurrency use remote **atomic** `If-Match`/`ETag` semantics or independently proven equivalent; naive GET then PUT is a time-of-check/time-of-use race. Local mocks can demonstrate intended client logic but **cannot prove Nutstore supports required semantics**. Real provider test is on hold until the user separately approves secured account configuration.
